---

# 🎯 Project Overview

This project is a classic Bomberman-style game developed using the Unity game engine.

The game includes:
- Player movement
- Bomb placement mechanics
- Explosion system
- Breakable and unbreakable walls
- Tile-based level structure
- Sprite-based 2D graphics
- Game assets and tile palettes

The project was created to practice Unity game development, game mechanics, and level design principles.

# 🧱 Gameplay Elements

## Walls

- **Unbreakable Walls**
  - Cannot be destroyed
  - Block explosions

- **Breakable Walls**
  - Destroyed by bomb explosions

## Bomb System

- Bombs explode after a delay
- Explosions spread in multiple directions
- Walls and objects interact with explosions
